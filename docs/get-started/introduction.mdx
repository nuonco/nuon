## What a component looks like

A Nuon app is a collection of components defined in TOML. A single Helm component looks like this:

```toml components/whoami.toml
type       = "helm_chart"
name       = "whoami"
chart_name = "whoami"

[public_repo]
repo      = "nuonco/demo"
directory = "eks-simple/src/components/whoami"
branch    = "main"
```

Components can also be Terraform modules, Kubernetes manifests, container images, or Docker builds. See [Configuration files](/configuration-files) for the full picture.

## How it works

![Runner architecture](/images/runner-architecture.png)

A small **Runner** binary lives inside the customer's cloud account, polls the **Control Plane** for jobs, and executes infrastructure operations locally. The Control Plane never has credentials or network access into customer accounts. See [Platform Architecture](/architecture/platform) for the full breakdown.
