**What you'll build:** a real Nuon install of an example app running in your own AWS account, using one of two paths.

**What you'll need:**

- A Nuon org and the Nuon CLI ([Quickstart](/get-started/quickstart) covers both)
- An AWS account ([set one up here](https://docs.aws.amazon.com/SetUp/latest/UserGuide/setup-overview.html))
- A working `nuon auth login` session

## Pick a tutorial

| Path | What you ship | Best for |
|---|---|---|
| [AWS EKS](/get-started/app-aws-k8s) | A Traefik `whoami` Helm app on EKS | Helm-shaped workloads |
| [AWS Lambda](/get-started/app-aws-lambda) | A Lambda function with DynamoDB and API Gateway | Serverless / event-driven workloads |

Both walk through the full lifecycle: app config → component → install → deploy. The two cloud-specific tutorials are the source of truth for the steps; this page just helps you choose.

## Other apps to explore

The [`example-app-configs` repository](https://github.com/nuonco/example-app-configs) contains additional apps you can clone and sync. Once you've completed one of the tutorials above, the pattern is:

```sh
cd example-app-configs/<app directory>
nuon apps create --name <app directory>
nuon apps sync
```
