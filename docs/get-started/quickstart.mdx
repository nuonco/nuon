You'll need two things before you start:
- A Nuon Cloud account — [sign up for the free trial](https://app.nuon.co/).
- An AWS account to deploy the app into.
</Note>

Copy and paste the flow below, or follow the walkthrough underneath for detail on each step of the Quickstart.

```sh
# 1. Install the CLI
brew install nuonco/tap/nuon

# 2. Authenticate with Nuon Cloud
nuon auth login

# 3. Clone Nuon's example apps repo 
git clone https://github.com/nuonco/example-app-configs

# 4. Create the app and sync its app branch, which starts the first run. (Kubernetes on AWS shown here)
cd example-app-configs/eks-simple
nuon apps create --name eks-simple
nuon branches sync --file branch.toml

# 5. Install the app in your AWS account
nuon installs create --name <install-name> --region <region>
```

## Install the CLI

```sh
brew install nuonco/tap/nuon
```

If you are not using Homebrew, refer to our [CLI](/cli) documentation for other installation options. If you use Nuon
BYOC or Self-Hosted, install the CLI version that matches your control plane instead. See
[Choosing a CLI version](/cli#choosing-a-cli-version).

## Authenticate to Nuon Cloud

```sh
nuon auth login
```

Follow the prompt in the browser and log in with a Google account.

## Clone the Example Apps Repo

Nuon maintains a [example apps](https://github.com/nuonco/example-app-configs) repo to demonstrate how to package various applications as app templates on AWS, Azure and GCP with various architectures like Kubernetes, VM and serverless.

```sh
git clone https://github.com/nuonco/example-app-configs
```

## Create the Example App and Run Its Branch

For the Quickstart, we're using an AWS EKS (Kubernetes) app template called eks-simple with a whoami Helm component,
an ACM certificate, and an Application Load Balancer to access the whoami service. View the app configuration in the
[example apps repo](https://github.com/nuonco/example-app-configs/tree/main/eks-simple) or with your IDE and the cloned
repo.

Create the app in Nuon, then sync its [app branch](/concepts/app-branches). The branch file, `branch.toml`, tells Nuon
which repository, directory, and git branch hold the app config:

```toml branch.toml (excerpt)
name = "main"

[public_repo]
directory = "eks-simple"
repo      = "nuonco/example-app-configs"
branch    = "main"
```

```sh
cd example-app-configs/eks-simple
nuon apps create --name eks-simple
nuon branches sync --file branch.toml
```

The sync shows the branch it will create and asks you to confirm. Creating the branch also starts its first run. The
run fetches the config from the example repo and builds the app's components (e.g., images, Helm, Kubernetes
manifests, Terraform) into OCI artifacts stored in your org's container registry. Nuon uses these artifacts when
installing your app. With no installs on the branch yet, the run stops after the build. Watch it with
`nuon branches runs --branch-id main`, and wait for the build to finish before you create an install.

## Install the Example App in AWS

Now create an install to deploy the app into your AWS account:

```sh
nuon installs create --name <install-name> --region <region>
```

- `--name` (`-n`) names this install.
- `--region` (`-r`) is the AWS region to provision into, for example `us-east-1`.

The CLI asks which app branch owns the install. Pick `main`. In a script, pass `--app-branch-id` with the branch ID
that `nuon branches list` prints.

## Deploy Your Own App

When you're ready to package your own software, wrap your existing Terraform, Helm, Kubernetes manifest, and container image assets into a Nuon app template. Commit the app config to your own GitHub repository, add a branch file that points at it, and the commands are the
same (`nuon apps create`, `nuon branches sync`, then `nuon installs create`). After that, pushing to the tracked git
branch rolls changes out. See [Configure app branches](/guides/app-branches).

Use agents like Claude Code to build your app template by learning from Nuon's example apps. See our [AI and App Template Building docs](/guides/agents/ai-and-apps) for more info.
