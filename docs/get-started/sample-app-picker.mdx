## Need Help Choosing?

<AccordionGroup>
  <Accordion title="I'm not sure which infrastructure to use">
    - **Lambda**: Best for APIs and event-driven workloads with minimal ops
    - **ECS**: Good for containers without Kubernetes complexity
    - **EKS/AKS/GKE**: Best for complex applications, microservices, or when you already use Kubernetes
  </Accordion>

  <Accordion title="My app uses multiple infrastructure types">
    Nuon apps can combine components. For example, you might use:
    - EKS for your main application
    - RDS (via Terraform) for your database
    - Lambda for background jobs

    Each component type can be mixed in a single app.
  </Accordion>

  <Accordion title="I need to use existing customer infrastructure">
    Check out the [Bring Your Own Network](/guides/bring-your-own-network) guide for deploying into existing VPCs and Kubernetes clusters.
  </Accordion>
</AccordionGroup>
