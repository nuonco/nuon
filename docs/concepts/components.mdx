title: "Components"

---

A Component represents a part of your App. Each component is configured in a TOML file inside a `components` directory in the root of your app directory.

Nuon supports the following component types:

- [Helm Charts](/guides/helm-chart-components) - any Helm chart in a repository
- [Terraform](/guides/terraform-components) - any Terraform module
- [Kubernetes Manifest](/guides/kubernetes-manifest-components) - any raw Kubernetes manifest
- [Docker Build](/guides/docker-build-components) - any Dockerfile that can be built
- [Container Images](/guides/container-image-components) - any prebuilt OCI image

Components can [depend on each other](/guides/component-dependencies) and share outputs through [variables](/guides/using-variables).

Components use either a public repo (`public_repo` block) or a private GitHub repo (`connected_repo` block) for source files. Read more about VCS configuration [here](/guides/vcs).

## Managing Components

See the [Managing Components](/guides/managing-components) guide for CLI commands to list, build, and manage components.
