This section of our docs outlines the basic concepts you should understand to get the most of Nuon and the BYOC model.

<CardGroup cols={2}>

  <Card title="Apps" icon="window-maximize" href="/concepts/apps">
    Package your application code and infrastructure as installable BYOC versions of your product.
  </Card>

  <Card title="Sandboxes" icon="border-all" href="/concepts/sandboxes">
    Manage the base layer infrastructure for your application in each customer's cloud account.
  </Card>

  <Card title="Components" icon="object-group" href="/concepts/components">
    Connect your existing Helm charts, Terraform modules, Kubernetes manifests, and container images.
  </Card>

  <Card title="Installs" icon="cube" href="/concepts/installs">
    Instances of your application deployed into a customer cloud account.
  </Card>

  <Card title="Actions" icon="circle-play" href="/concepts/actions">
    Automate operational tasks like health checks, migrations, and day-2 operations.
  </Card>

  <Card title="Workflows" icon="circle-nodes" href="/concepts/workflows">
    Lifecycles for deploying, updating, and tearing down apps and components.
  </Card>

  <Card title="Policies" icon="shield" href="/concepts/policies">
    Enforce compliance and security standards across your infrastructure deployments.
  </Card>

  <Card title="Runners" icon="shoe-prints" href="/concepts/runners">
    Egress-only agents that deploy and manage installs in customer cloud accounts.
  </Card>

  <Card title="Inputs" icon="sliders" href="/concepts/app-inputs">
    Customer-provided values that configure your app per install.
  </Card>

  <Card title="Operation Roles" icon="user-lock" href="/concepts/operation-roles">
    Assign different IAM roles to different operations for least-privilege access.
  </Card>

  <Card title="App Variables" icon="code" href="/concepts/app-variables">
    Store values through the API to be used across installs of an app.
  </Card>

  <Card title="Secrets" icon="key" href="/concepts/app-secrets">
    Define and manage sensitive values for use in app configuration.
  </Card>

</CardGroup>
