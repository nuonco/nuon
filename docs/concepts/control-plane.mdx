---
title: "Control Plane"
description: "Use Nuon's Control Plane to create a simple install"
---

Inside your org, navigate to any application.

In the upper-right corner, you'll see a button labeled "create install."

![Create install button](../images/concepts/control-plane/create-install-button.png)

A form will pop-up where you can enter inputs.

![Install form popup](../images/concepts/control-plane/install-form.png)

Once filled out, click "create install," and your install will start deploying.

![Provisioning install](../images/concepts/control-plane/provisioning-install.png)
