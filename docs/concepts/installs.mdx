An install is one deployment of your App Template into a customer's cloud account. It inherits the sandbox and
components your App Template defines, and deploys the latest build of each component.

Inputs are how you tailor an install to each customer. Fill them in when you create the install in the dashboard, or
set them in an [install config](/guides/install-configs) when you create installs at scale.
