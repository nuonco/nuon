## Deploy

## Setup

- **Set inputs.** API keys, cloud region, instance size, or the release to run. Fill them in when you create the
  install, or set them in an [install config](/guides/install-configs) for installs at scale.
- **Fit the customer's architecture.** The [stack](/concepts/stacks) creates a fresh network or builds on the
  customer's VPC or cluster.
- **Override one install.** A [component override](/guides/component-overrides) changes Helm values or Terraform
  variables for that install only.

## Health

- **[Health checks](/guides/health-checks)** show whether every component is running, with alerts to Slack and
  webhooks.
- **[Install telemetry](/concepts/install-telemetry)** forwards logs, metrics, and traces to your observability
  backend.
