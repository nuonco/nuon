Every action in the Nuon [web app](/concepts/web-app) is backed by the [Control Plane API](https://api.nuon.co/docs/index.html). Use the API to embed install management in your own product, automate provisioning at scale, or integrate Nuon into an existing workflow engine.

## Quick access

From your org, open the API docs in your browser with authorization pre-applied:

```bash
nuon docs api
```

If you open `https://api.nuon.co/docs/index.html` directly, click **Authorize** to set your org credentials.

## End-to-end examples

For a step-by-step walkthrough of creating, provisioning, updating, and deprovisioning an install over the API — with both curl and Go SDK examples — see the [Integrate into your Product guide](/guides/control-plane-integration).
