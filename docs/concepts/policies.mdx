---
title: "Policies"
description: "Enforce compliance, security, and operational standards across your infrastructure deployments."
---

Policies are rules that validate your infrastructure during builds and deploys. Each policy either **denies** (blocks the operation) or **warns** (logs a warning but allows it to continue).

Policies are written in [OPA Rego](https://www.openpolicyagent.org/docs/latest/policy-language/) or [Kyverno](https://kyverno.io/) YAML, and are defined in a `policies.toml` file at the root of your app directory.

## Policy Types

| Type | Applies To | Engine | Evaluation Phase |
|------|------------|--------|------------------|
| `container_image` | External container images | OPA | Build |
| `helm_chart` | Helm chart components | OPA | Deploy |
| `kubernetes_manifest` | Kubernetes manifest components | OPA | Deploy |
| `terraform_module` | Terraform module components | OPA | Deploy |
| `kubernetes_cluster` | Kubernetes cluster resources | Kyverno | Deploy |
| `sandbox` | Sandbox infrastructure | OPA | Sandbox run |

## Configuration

See the [Configuring Policies](/guides/configuring-policies) guide to add policies to your app, and the [External Image Policies](/guides/external-image-policies) guide for container image validation patterns.
