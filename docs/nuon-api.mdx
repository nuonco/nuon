Everything the dashboard and CLI do goes through the Nuon API, so you can automate it from your own product:

- **Onboard a customer.** Create an install with `POST /v1/installs`, then send the customer the link to create the
  stack in their own cloud account. The customer enters any secret values there, so secrets never pass through the
  API. See [Build a UI integration](/guides/ui-integration).
- **Track progress.** Subscribe to [webhooks](/guides/webhooks) for workflow and health events.
- **Collect customer approvals and input changes.** See
  [Let customers manage their install](/guides/control-plane-integration).

## Getting an API token

You'll need an access token to use the Nuon API. Create an [API token](/concepts/api-tokens) from the Nuon [Dashboard][1] or the Nuon CLI. Tokens are shown only once, so store them somewhere safe.

```sh
nuon login
nuon service-accounts create --name my-service-account --role org_read_only
nuon service-accounts tokens create --id <account-id> --name my-token
```

With the API itself, create a service account with `POST /v1/service-accounts`, then a token for it with `POST /v1/tokens`.

For automation and CI/CD, we recommend using [OIDC Federation](/concepts/oidc-federation) to avoid storing long-lived tokens.

## Using the Swagger API Reference

You can call the Nuon API endpoints from the API Reference by visiting the [Swagger API Reference](https://api.nuon.co/docs/index.html)

## Using the API 

You can call the Nuon API endpoints from the API Reference by adding `Bearer <your-api-token>` to the "Authorization" field in each endpoint card. Verify your API token with the [current-user](/api-ref/general/get-current-user) endpoint.
