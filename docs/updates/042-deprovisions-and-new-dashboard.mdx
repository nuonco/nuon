## BYOC telemetry

Every install's logs, metrics, and traces in your backend.

- Apps send OpenTelemetry to a private OTLP endpoint in each install
- The runner forwards it to your relay, which exports to any OTLP backend
- Records are stamped with verified `nuon.org.id`, `nuon.app.id`, and `nuon.install.id`
- No backend credentials in customer accounts
- Customers can disable the endpoint in their stack
- Org default plus per-install overrides

```toml
OTEL_EXPORTER_OTLP_PROTOCOL = "http/protobuf"
OTEL_EXPORTER_OTLP_ENDPOINT = "{{ .nuon.install_stack.outputs.telemetry_endpoint }}"
```

## Deprovisioning

Choose what stays in the customer's account on teardown.

- `[teardown] retain` removes listed resources from state and leaves them running
- The teardown plan marks each retained resource with a **Retain** action
- The plan fails if a retained resource depends on something being destroyed
- `apply_on_teardown = false` skips a policy during teardowns and keeps it on for deploys
- Failed plan steps can be skipped
- Deprovisions show on the install's deployments page

```toml components/database.toml
[teardown]
retain = [
  "aws_rds_cluster.main",
  "aws_rds_cluster_instance.main",
]
```

```toml policies.toml
[[policy]]
type              = "terraform_module"
engine            = "opa"
contents          = "./protect-rds-cluster.rego"
apply_on_teardown = false
```
