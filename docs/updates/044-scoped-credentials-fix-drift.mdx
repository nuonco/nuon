## Scoped credentials

- [Service account tokens](/concepts/api-tokens) replace personal tokens for API and CI access, each with one role in one org
- Runners use short-lived credentials, scoped to each job

Move CI and scripts to service account tokens. Personal tokens keep working until you revoke them.

## Fix drift from the Components page

- See [drift](/concepts/workflows#drift-detection) and undeployed changes together on each install
- Redeploy just the component that drifted

## Other updates in this release

### Upgrade the CLI

`nuon auth login` now fails on older versions to keep you current with the latest security fixes. Run `brew upgrade nuonco/tap/nuon`.

### More accurate change previews

Change previews now catch edits in nested settings, like deployment options, health checks, permissions, secrets, actions and runbooks.

### Skip applies with policies

Give a policy check `custom.action: skip_apply`, and Nuon skips the apply for any Terraform component or sandbox it matches. Components that depend on it still get its last outputs.

<Card title="Configuring policies" icon="scale-balanced" href="/guides/configuring-policies" horizontal />

### Pull request previews

See what a pull request would change before you merge it. Each open pull request on an app branch gets a page with its config diff, commit, and preview step status.

<Note>Pull request previews are in early access. [Contact us](mailto:support@nuon.co) to turn them on for your org.</Note>

### CLI versions for BYOC control planes

If you run a Nuon BYOC control plane in your own cloud, install the CLI version that matches it alongside the latest.
