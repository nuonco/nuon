## `replay-stack` CLI extension

A new [CLI extension](/concepts/cli) for replaying [install stacks](/concepts/stacks). Useful for re-running a stack deployment without recreating the install — handy for debugging stack failures or applying updated stack templates.

```bash
nuon ext replay-stack
```

Locally-installed extensions now also show up in `nuon ext list`, and `nuon ext` no longer requires the `NUON_PREVIEW` flag.

## Other improvements

- **Horizontally scrollable logs** — long log lines no longer wrap unreadably; scroll sideways to read full output.
- **Empty states** — onboarding flows and empty dashboard pages have clearer prompts to get you to your first install faster.
- **`nuon apps sync`** — the CLI now honors the currently selected app when running `apps sync` / `sync`.
- **Slack auto-link** — new orgs are automatically linked to their Slack workspace at creation time.

## Bug fixes

- Auto-approved workflows no longer show a stale approval banner, and the "Deploy all" toast now reports the correct message.
- The action run cancel button and log step rendering have been fixed.
- VM shutdown, re-enqueue, and approve-all paths now behave correctly under load.
- "All workflows" in the install nav now routes to the workflows page.
- Action and install detail pages no longer get stuck on loading skeletons.
- Long-running activity heartbeats and queue cancellation no longer time out prematurely.
- Terraform provider mirror builds now work for orgs that also have `docker_build` components.
- Runner health checks are no longer soft-deleted, so health state stays accurate after restarts.
