## Other updates in this release

### Plan diffs in the CLI

Review a plan's changes from your terminal or a CI job.

```sh
nuon installs workflows steps diff -w <workflow-id> -s <step-id>
```

### CLI versions for BYOC control planes

If you run a Nuon BYOC control plane in your own cloud, install the CLI version that matches it alongside the latest.
