# Branch

Field reference for a standalone app branch config (`branch.toml` at the app root, or one file per branch under
`branches/`). How-to: [Configure app branches](/guides/app-branches). Sync with
`nuon branches sync --file <path>` (file or directory).

Exactly one of `[connected_repo]` or `[public_repo]`. When `install_groups` is non-empty, exactly one group must set
`default = true`. `[preview]` is optional but recommended for testing before a change merges into the tracked
branch; defaults for preview runs started by a pull request or by `nuon branches preview` (not used by fleet
push/trigger runs).

## Properties

| Property | Description | Values | Example |
|----------|----------|----------|----------|
| **`name`**<br/>string | Name of the app branch in Nuon | **Required** | `"main"` |
| **`connected_repo`**<br/>[ConnectedRepoConfig](#connected_repo) | Connected GitHub repo the branch tracks | Optional | - |
| **`public_repo`**<br/>[PublicRepoConfig](#public_repo) | Public git repo the branch tracks | Optional | - |
| **`install_groups`**<br/>[array](#install_groups) | Ordered install groups for this branch | Optional | - |
| **`preview`**<br/>[AppBranchPreviewConfig](#preview) | Default preview settings for this branch | Optional | - |
| **`run`**<br/>[AppBranchRunConfig](#run) | Which VCS events automatically start a run | Optional | - |
| **`post_deploy_runbooks`**<br/>array | Runbook names to run on each install, in order, after its deploy succeeds (resolved to IDs at sync) | Optional | - |
| **`ignore_changes_regex`**<br/>string | RE2 regex matched against every changed file path; a run whose entire changed set matches is not attempted | Optional | - |
| **`send_statuses_on_ignore`**<br/>boolean | Send a successful commit status when a run is skipped by `ignore_changes_regex` | Optional | - |

### `connected_repo`

| Property | Description | Values | Example |
|----------|----------|----------|----------|
| **`repo`**<br/>string | Connected repository as `owner/name` | **Required** | `"acmeco/my-app-config"` |
| **`directory`**<br/>string | Path to the app config inside the repo | **Required** | `"."`, `"eks-simple"` |
| **`branch`**<br/>string | Git branch to track | **Required** | `"main"`, `"release"` |

### `public_repo`

| Property | Description | Values | Example |
|----------|----------|----------|----------|
| **`repo`**<br/>string | Public repository as `owner/name` | **Required** | `"nuonco/example-app-configs"` |
| **`directory`**<br/>string | Path to the app config inside the repo | **Required** | `"."`, `"eks-simple"` |
| **`branch`**<br/>string | Git branch to track | **Required** | `"main"`, `"release"` |

### `install_groups`

| Property | Description | Values | Example |
|----------|----------|----------|----------|
| **`name`**<br/>string | Name of the install group | **Required** | `"stage"`, `"production"` |
| **`order`**<br/>integer | Deployment order (lower runs first) | Optional | `1`, `2` |
| **`label_selector`**<br/>object | Label key-value pairs that match installs into this group | Optional | `{ env = "stage" }` |
| **`default`**<br/>boolean | Catch-all for installs on this branch that match no other group. Exactly one group must be default when any groups are declared | Optional | `true` |
| **`auto_approve_on_policies_passing`**<br/>boolean | Auto-approve this install group's plan when all policy checks pass. Defaults to false | Optional | - |

### `preview`

Optional but recommended for testing a change before it merges into the tracked branch. For `plan-only` and
`apply`, set one of `label_selector`, `install_name`, or `install_id`. `mode = "none"` and `build-only` do not
take a target install. CLI preview modes are `plan-only`, `apply`, and `build-only` (`none` is config-only for
automatic PR previews).

| Property | Description | Values | Example |
|----------|----------|----------|----------|
| **`mode`**<br/>string | Preview run mode | Optional<br/>`"none"`, `"plan-only"`, `"apply"`, `"build-only"` | `"plan-only"` |
| **`install_id`**<br/>string | Default install ID for preview runs | Optional | - |
| **`install_name`**<br/>string | Default install name for preview runs (resolved to an ID at sync) | Optional | - |
| **`label_selector`**<br/>object | Labels that select the default preview install | Optional | `{ preview = "true" }` |
| **`set_statuses`**<br/>boolean | Set GitHub commit statuses for preview runs | Optional | - |
| **`comment`**<br/>boolean | Comment on the pull request with preview results | Optional | - |
| **`ignore_drafts`**<br/>boolean | Skip draft PRs until ready for review. Defaults to true | Optional | - |
| **`react`**<br/>boolean | Add a GitHub eyes reaction when a preview starts. Defaults to true | Optional | - |

### `run`

| Property | Description | Values | Example |
|----------|----------|----------|----------|
| **`mode`**<br/>string | Automatic run mode. Default when omitted is push | Optional<br/>`"push"`, `"on_tag"`, `"on_github_label"`, `"manual_only"` | `"push"` |
| **`tag_prefix`**<br/>string | Case-sensitive git tag prefix required by `on_tag` | Optional | `"v"` |
| **`github_label`**<br/>string | Exact pull request label required by `on_github_label` (needs `connected_repo`) | Optional | `"deploy"` |
