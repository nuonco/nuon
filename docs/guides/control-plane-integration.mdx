Once a customer's install is running, they'll still need to make a few changes themselves, such as fixing a setting,
approving an update, or removing your product from their account. This guide covers the API calls behind those
controls in your app. For first-time setup, see [Build a UI integration](/guides/ui-integration).

Every call here uses your app's [service account](/concepts/service-accounts) token. Calls that start work accept a
`request_id`, so a retry after a timeout returns the original workflow. See
[Idempotent operations](/guides/idempotent-operations).

## Change a setting

When a customer fixes a setting, such as their domain, update the install's [inputs](/concepts/app-inputs). Nuon
redeploys the parts of your product that use them.

<CodeGroup>
```bash curl
curl -X PATCH https://api.nuon.co/v1/installs/$INSTALL_ID/inputs \
  -H "Authorization: Bearer $NUON_API_TOKEN" \
  -H "X-Nuon-Org-ID: $NUON_ORG_ID" \
  -H "Content-Type: application/json" \
  -d '{
    "inputs": {
      "domain": "new-domain.example.com",
      "replicas": "3"
    }
  }'
```

```go Go
inputs, workflowID, err := client.UpdateInstallInputs(
    context.Background(),
    installID,
    &models.ServiceUpdateInstallInputsRequest{
        Inputs: map[string]string{
            "domain":   "new-domain.example.com",
            "replicas": "3",
        },
    },
)
```
</CodeGroup>

## Pick up a changed secret

Customers keep secrets in their own cloud's secret manager. After they change one, sync it so your product uses the
new value.

<CodeGroup>
```bash curl
curl -X POST https://api.nuon.co/v1/installs/$INSTALL_ID/sync-secrets \
  -H "Authorization: Bearer $NUON_API_TOKEN" \
  -H "X-Nuon-Org-ID: $NUON_ORG_ID" \
  -H "Content-Type: application/json" \
  -d '{"plan_only": false}'
```

```go Go
// SyncSecrets is not yet exposed in the public SDK.
// Use the REST API directly or contact support for SDK updates.
```
</CodeGroup>

## Approve changes

If installs pause for approval, give the customer an **Approve** button for each change, including new versions of
your product. One button that maps to `approve-all` keeps it simple.

<CodeGroup>
```bash curl
curl -X PATCH https://api.nuon.co/v1/workflows/$WORKFLOW_ID \
  -H "Authorization: Bearer $NUON_API_TOKEN" \
  -H "X-Nuon-Org-ID: $NUON_ORG_ID" \
  -H "Content-Type: application/json" \
  -d '{"approval_option": "approve-all"}'
```

```go Go
approveAll := models.AppInstallApprovalOptionApproveDashAll
workflow, err := client.UpdateWorkflow(
    context.Background(),
    workflowID,
    &models.ServiceUpdateWorkflowRequest{
        ApprovalOption: &approveAll,
    },
)
```
</CodeGroup>

## Remove your product

Removing an install runs setup in reverse:

1. Deprovision your product from the customer's account.
1. The customer removes the runner, following the steps in the deprovision workflow.
1. Delete the install from Nuon.

### Deprovision

Deprovisioning removes your product and its base infrastructure from the customer's account. Like setup, it can pause
for approval.

<CodeGroup>
```bash curl
curl -X POST https://api.nuon.co/v1/installs/$INSTALL_ID/deprovision \
  -H "Authorization: Bearer $NUON_API_TOKEN" \
  -H "X-Nuon-Org-ID: $NUON_ORG_ID" \
  -H "Content-Type: application/json" \
  -d '{"plan_only": false}'
```

```go Go
err := client.DeprovisionInstall(context.Background(), installID)
```
</CodeGroup>

### Delete the install

Once everything is gone from the customer's account, delete the install.

<CodeGroup>
```bash curl
curl -X DELETE https://api.nuon.co/v1/installs/$INSTALL_ID \
  -H "Authorization: Bearer $NUON_API_TOKEN" \
  -H "X-Nuon-Org-ID: $NUON_ORG_ID"
```

```go Go
deleted, err := client.DeleteInstall(context.Background(), installID)
```
</CodeGroup>

### Forget an install

If something outside Nuon breaks the customer's account badly enough that deprovisioning can't run, forget the install
instead. Nuon drops its record without touching the account, and you can start a fresh install.

<CodeGroup>
```bash curl
curl -X POST https://api.nuon.co/v1/installs/$INSTALL_ID/forget \
  -H "Authorization: Bearer $NUON_API_TOKEN" \
  -H "X-Nuon-Org-ID: $NUON_ORG_ID" \
  -H "Content-Type: application/json" \
  -d '{}'
```

```go Go
forgotten, err := client.ForgetInstall(context.Background(), installID)
```
</CodeGroup>
