The [CLI](/cli) provides commands to manage components and builds. To see all available commands, run `nuon components --help`.

To learn more about components, see the [Components](/concepts/components) concept page.

<Note>
Select an app template using `nuon apps select` before using component commands, or pass the `-a` flag.
</Note>

## Common Commands

List components:

```sh
nuon components list
```

Get a component:

```sh
nuon components get -c <component_id or name>
```

Print the latest config:

```sh
nuon components latest-config -c <component_id or name>
```

To delete a component, remove its TOML file from the app directory, then commit and push to the git branch your [app branch](/guides/app-branches) tracks. The next branch run removes it.

## Builds

All components must be built before creating or updating an install. A branch run builds automatically when component TOML files or related files (e.g., Helm `values.yaml`) change. To rebuild every component, run `nuon branches trigger --branch-id <branch> --force`.

If component source files change in git, push those changes first, then build manually:

Create a build:

```sh
nuon builds create -c <component_name>
```

List builds:

```sh
nuon builds list -c <component_name>
```

Get build details:

```sh
nuon builds get -b <build-id> -c <component_name>
```

Show build logs:

```sh
nuon builds logs -b <build-id> -c <component_name>
```

<Note>
Omit the `-c` flag to list builds for all components in the selected app.
</Note>
