Connect your agent once. Use any coding agent to write your app config. Then let your agent operate your customers'
installs through the Nuon MCP server.

## Set up

A one-time step: register the Nuon MCP server with your client. See [Setup](/guides/agents/setup) for other clients
and sign-in details.

<McpInstallPicker />

## Build

Your app config is TOML in git, so any coding agent can write it. These pages are tips for doing that well:

- [Start from the example app templates](/guides/agents/ai-and-apps)
- [Writing policies](/guides/agents/writing-policies) with the `write-rego-policy` skill
- [Customizing READMEs](/guides/agents/customizing-readmes) with the `write-readme` skill

## Operate

This is where your agent does the most for you. Once an install is running, ask it to do the day-2 work on your
customers' installs:
