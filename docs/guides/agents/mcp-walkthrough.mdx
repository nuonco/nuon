## Prerequisites

- [Nuon CLI](/cli) installed and authenticated (`nuon auth login`, `nuon orgs select`)
- An LLM client that supports MCP (Cursor, Claude Code, etc.)

## Steps

<Steps>
<Step title="Register the MCP server">

Add the stdio proxy. Token and org stay in `~/.nuon`.

Every client runs `nuon agents mcp --allow-writes`. Configured by file, that is this block (Amp uses the literal `amp.mcpServers` key instead of `mcpServers`):

```json
{
  "mcpServers": {
    "nuon": {
      "command": "nuon",
      "args": ["agents", "mcp", "--allow-writes"]
    }
  }
}
```

<CodeGroup>
```bash Claude Code
claude mcp add --transport stdio nuon -- nuon agents mcp --allow-writes

# or save the block above as .mcp.json in the project
```

```bash Amp
amp mcp add nuon -- nuon agents mcp --allow-writes

# or the same entry under "amp.mcpServers" in ~/.config/amp/settings.json
```

```bash Cursor
# Cursor has no mcp add: save the block above as ~/.cursor/mcp.json
# (all projects) or .cursor/mcp.json (one project), then:
agent mcp enable nuon
```
</CodeGroup>

Examples include `--allow-writes` so mutating tools are available. Your token must have create permission.

The proxy derives its URL from the configured API hostname (`api.<hostname>` becomes `mcp.<hostname>/mcp`). Pass `--url` when the MCP URL does not follow from the API URL — for example, for a self-hosted or Nuon BYOC control plane, or any deployment where the hostnames differ. Use `--name` to rename it in the client's MCP list. Full examples: [Connect](/guides/agents/overview#connect) and [Overriding the MCP URL](/guides/agents/overview#overriding-the-mcp-url).

`nuon agents help` prints all of this against your own config.

</Step>

<Step title="Verify context">

```bash
nuon agents context
```

Confirm you are authenticated and an org is selected. If not, run `nuon auth login` and `nuon orgs select`.

</Step>

<Step title="Ask a first question">

In the LLM client, paste:

```
Who am I, and what installs are in this org?
```

The client should call `whoami` and `list_installs`. You do not need `select_org` when using the stdio proxy (org is already in `X-Nuon-Org-ID`).

More prompts: [Sample queries](/guides/agents/sample-queries).

</Step>
</Steps>
