Change 2 — Synced Filter (Active-Only by Default)

API Endpoints — synced query parameter
GET /v1/installs/:id/components
synced param exists, default=true
→
WHERE component_id = ANY(app_configs.component_ids)
GET /v1/installs/:id/actions
synced param new, default=true (was hardcoded true)
→
WHERE EXISTS (action_workflow_configs JOIN installs)
GET /v1/installs/:id/runbooks
synced param exists, default=true
→
WHERE EXISTS (runbook_configs JOIN installs)
CLI
--all flag
nuon installs components list → synced=true (default)
nuon installs components list --all → synced=false
Dashboard UI
"Show removed" toggle
Toggle off (default) → synced=true → show current entities
Toggle on → synced=false → show all including removed
synced=true (default)
Component A (in current config) → shown
Component B (in current config) → shown
Component C (removed in v3) → hidden
synced=false (--all)
Component A (in current config) → shown
Component B (in current config) → shown
Component C (removed_at_app_config_id: cfg...) → shown
