# Lite dashboard (proof of concept)

`client/lite/` is a **proof of concept**. It is not the dashboard UI to copy from.

**Do not import, copy, or reuse Lite components, hooks, providers, utils, or patterns in `client/` (the production SPA), or anywhere else in the repo.** Production work belongs in `client/components/`, `client/views/`, `client/hooks/`, and the rest of the existing dashboard. Lite may later become the dashboard; until then it is an isolated experiment.

If you are working on Lite itself, stay inside this directory. If you are working on the production dashboard, ignore this tree.
