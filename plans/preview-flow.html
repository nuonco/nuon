Workflow — synthetic preview install group

Deploy run vs preview run

Deploy run (Preview = nil)

  1. Primary Trigger run button
  2. No AppBranchRunPreview row
  3. Workflow iterates install_groups
  4. Steps: plan → approve → deploy per group

Preview run (Preview ≠ nil)

  1. Caret menu → Preview run / quick action
  2. Defaults from preview_config, optional override
  3. Single synthetic install group at runtime
  4. Excluded from baseline / trigger active sets
