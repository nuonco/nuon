First run vs subsequent run

First run (BaseRunID = nil)

  1. Comparison row with empty blobs
  2. Skip diff computation
  3. Full build — everything is new
  4. labels.builds_completed = true on success

Subsequent run (BaseRunID set)

  1. BaseRun = latest deploy with builds_completed=true
  2. Git clone + diff → GitDiff blob
  3. FullDiff + ConfigDiff with SourceChanged
  4. Builds consume comparison before setting builds_completed
